# G925 PanVK kbase CSF submit telemetry (2026-11-25)

## Purpose

First physical-device capture of the opt-in PANVK_DEBUG=perf diagnostics added to the kbase CSF submit path. The flag was configured only on the AIO Graphics Test 64bit shortcut whose Winlator container is PanVK_G925_Test (Proton 11.0-7 arm64ec). The System control shortcut and Container-1 were not changed.

The environment setting was reopened and verified to persist as PANVK_DEBUG=perf before launch.

## Device and workload

- Device: Samsung Galaxy Tab S11 SM-X730, Immortalis-G925 / MT6991.
- OS / compatibility: Android 17; Winlator Ludashi 5.0; Proton 11.0-7 arm64ec.
- Custom ICD loaded: Mesa 27.0.0-devel-cdb8aa7/libvulkan_panfrost.so.
- Workload: AIO Graphics Test 64bit, Vulkan cube benchmark, 1280x720 guest desktop, 15.000 seconds.
- The Android loader log for the benchmark process confirms the cdb8aa7 custom ICD path.
- Benchmark process PID in logcat: 22383. Telemetry window: 2026-11-25 21:52:54.438–21:53:14.695 (device local time).

## kbase CSF telemetry

The captured log contains 27,855 PANVK_PERF kbase-csf records from PID 22383, with sequence values 4–27858 and timestamps spanning 20.257 seconds. Two additional startup records came from the Winlator explorer.exe process (PID 22350). The main-process trace is complete for its observed sequence range.

cpu_wait was 0 for all 27,855 main-process records. cpu_wait_fallback was 0 for every record. This means the instrumented CPU semaphore-wait fallback path was not taken during this AIO workload; it does not prove that every GPU-side synchronization path is correct or stall-free.

## Fault scan and limitations

The captured log window contained no matches for GROUP_ERROR_FATAL, 0x24c00488, SHAREABILITY_FAULT, VK_ERROR, assert, or FATAL.

This is a successful synthetic Vulkan workload and a first successful telemetry capture. It is not Vulkan CTS, BannerHub, a real game, or proof of universal CSF synchronization correctness. The counters describe kbase submission activity; they are not GPU execution timestamps and do not measure actual vertex, fragment, or compute overlap on the hardware.
