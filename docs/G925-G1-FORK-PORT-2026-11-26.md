# G1 Ultra fork port and Psycho-Sleuth run (2026-11-26)

## Ported changes

- Bifrost register allocation skips groups of zero-live SSA nodes while scanning interference candidates.
- Geometry shader offset tables are cached within a command buffer; the source arrays are immutable shader-variant data.
- Large descriptor BO reuse is opt-in through `PANVK_DESC_BIG_REUSE=1`; it remains disabled for gameplay until separately validated.
- The opt-in is read on command-buffer creation without a mutable process-global cache, avoiding a first-use race when command buffers are created concurrently.

## Build and package

Android arm64 build succeeded in `build-android-fork-exp` with the local Android NDK r30. The telemetry package includes a pool-exhaustion diagnostic that distinguishes free-set exhaustion from descriptor-heap exhaustion. The gameplay package has the same optimized library; use it with `PANVK_DEBUG` unset and descriptor BO reuse disabled. No frame-rate or CPU/GPU timing comparison has been completed, so no performance gain is claimed.

## Psycho-Sleuth test

The Galaxy Tab S11 test container and the game shortcut both selected `PanVK G925 G1 optimizations - telemetry v2` for Renderer Driver and Vulkan Driver. The run returned to Winlator with a white game window. The driver logged `VK_ERROR_OUT_OF_POOL_MEMORY` and the added marker reported:

`free_set=0 max_sets=49152 heap_free=6834624 requested=64 num_descs=2 variable_count=0`

This identifies exhaustion of the descriptor set slots for a pool whose descriptor heap still had about 6.5 MiB free. The heap was not exhausted (`uses_heaps=0` in resource-table records); no `GPU_RES_HEAPS`, `GPU_BIND_HEAP`, or `GPU_DESC_SET_COPY` events appeared. The marker diagnosis is now concrete, but the game's handling of the returned allocation error and the root reason this pool reaches 49,152 sets still need investigation. The demo remains visually broken; this is not a passing compatibility result.

Captured runtime flags were configured as `PANVK_DEBUG=startup,dump,perf`, without `trace`. The latest short run did not emit usable frame-time measurements; its descriptor dumps are intentionally verbose.
