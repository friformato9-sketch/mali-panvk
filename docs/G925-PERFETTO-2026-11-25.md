# G925 Android Perfetto capture (2026-11-25)

## Capture setup

- Device: Samsung Galaxy Tab S11 SM-X730, Immortalis-G925 / MT6991, Android 17.
- Winlator: Ludashi 5.0; AIO Graphics Test 64bit shortcut using PanVK_G925_Test.
- Driver: Mesa 27.0.0-devel-cdb8aa7/libvulkan_panfrost.so.
- PANVK_DEBUG=perf remained enabled only on this PanVK AIO shortcut.
- Perfetto trace duration: 25 seconds; ring buffer: 64 MiB.
- Configured data sources: linux.ftrace, android.surfaceflinger.frametimeline, android.gpu.memory, android.power.
- ftrace categories requested: gfx, view, sched, freq, idle, power, thermal, input, wm and am.
- App filtering: com.ludashi.benchmark.

The trace was copied to Helios-14 and parsed with Perfetto Trace Processor. The parser reported two systrace_parse_failure importer warnings. The trace also contains scheduler/frequency events, QueueSubmit slices, frame-timeline rows and the GPU-frequency counter. Results below are limited to those populated tables.

## What this trace does not expose

- gpu_slice contained zero rows.
- There are no Mali render-stage or hardware queue execution slices for vertex/tiler, fragment or compute.
- No gpu.counters / gpu.renderstages producer was registered in the device's Perfetto data-source list.
- Android property graphics.gpu.profiler.support is true, but graphics.gpu.profiler.support.render_stages is unset. The general property alone does not establish that the render-stage producer is enabled.
- The kernel exposes /sys/class/devfreq/48000000.mali, but adb shell is denied access to its cur_freq and related entries. No permissions or root state were changed.

Therefore this trace can correlate application-side API submission, CPU scheduling and GPU frequency, but it cannot prove hardware overlap or identify vertex/fragment/compute engine stalls.

The FrameTimeline tables are populated, but their rows describe Android/SurfaceFlinger host surfaces and Winlator presentation layers. They are not the AIO guest's internal Vulkan frame samples and must not be used as a replacement for the AIO CSV FPS values.
