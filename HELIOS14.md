# Helios-14 Android PanVK development

This fork starts from JimVulkan's PanVK-on-kbase Mesa port. The target is the Samsung Galaxy Tab S11 (Dimensity 9400+, Immortalis-G925 MC12).

## Quick links
- [G-925 project notes](docs/G925-PORTING.md)
- [Helios-14 WSL build setup](build-support/helios14-wsl-setup.sh)

This is an experimental community project. The official upstream package is the known-good baseline; build and test fork artifacts separately before using them in an emulator. Do not replace the device's system GPU driver.
